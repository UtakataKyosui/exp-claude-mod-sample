RUNTIME

フックモジュールは DOM も Node もない専用サンドボックスで実行される。import は実行時には空になる純粋な型のためのモジュールで、JSX は h / Fragment にコンパイルされる(React ではない)。Box / Text のような UI 要素はグローバルに生えているのではなく、描画対象サーフェスのテーブルから都度取り出す — const { Box, Text } = $.ui.resolve(e)。

ファイル自体は手編集の対象外。プラグインが増えるたびに /plugin-types で再生成され、有効なプラグインごとの契約は隣接する claude-code-plugins/<plugin>.d.ts に個別出力される。

プラグインによる拡張パターン

プラグインは自分の .d.ts(plugin.json の "types" で指定)を通じて EngineInterface に新しい「名詞」を declaration merging で追加できる。依存する側のプラグインは import も reference も書かずに、この include 済みフォルダ経由で型が見える。

プラグイン本体の型付け
// hooks/index.ts
import type { Register } from 'claude-code'

export const register: Register = (on, options) => {
  on('tool.call', ($, e, next) => {
    // e.tool === "Bash" でここが narrowing される
    return next()
  })
}
新しい noun を $ へ追加する
// types/topo.d.ts
export type Topo = { /* ... */ }

declare module 'claude-code' {
  interface EngineInterface {
    topo: Topo
  }
}
